# Консольный калькулятор и конвертер величин

Автор проекта: Кирилл Кафтанов.

## 1. Описание проекта

Лабораторная работа № 1 — консольное приложение на Python, объединяющее арифметический калькулятор и конвертер величин. Программа организована как пакет `toolkit` с командным интерфейсом (CLI). Вычисления, проверка входных данных и обработка ошибок находятся в отдельных модулях.

## 2. Используемые технологии

- Python 3.14.2;
- `uv` для установки пакета и управления зависимостями;
- стандартный модуль `decimal` для арифметики калькулятора;
- `pytest` для автоматических тестов;
- `Ruff` для статической проверки кода;
- `setuptools` для сборки пакета из каталога `src`.

## 3. Установка и запуск

Из корневого каталога проекта выполни:

```bash
uv sync
```

Справка по программе:

```bash
uv run python -m toolkit --help
```

После активации виртуального окружения можно использовать и команду `python -m toolkit ...` без `uv run`.

Для запуска необходимо указать подкоманду `calc` либо `convert`: запуск `python -m toolkit` без подкоманды выводит ошибку аргументов.

## 5. Командный интерфейс

Поддерживаются следующие команды:

```bash
uv run python -m toolkit calc "2 + 3 * 4"
uv run python -m toolkit convert 100 --from cm --to m
uv run python -m toolkit --help
```

Результат успешной команды выводится в `stdout`, код завершения процесса — `0`. Сообщения об ошибках выводятся в `stderr`, код завершения — `2`.

Выражение калькулятора передаётся **одним аргументом**, поэтому выражения с пробелами и скобками заключаются в кавычки. Калькулятор поддерживает выражения, начинающиеся с минуса, например `calc "-5+10"`.

## 6. Калькулятор

Основная функция: `calculate(expression)` в `calculator.py`.

Поддерживаются целые и десятичные числа (включая записи `.5`, `5.`), четыре операции `+`, `-`, `*`, `/`, унарные `+` и `-`, круглые скобки, вложенные выражения, пробелы между токенами, а также научная запись чисел с `e` или `E` (например, `1.5e-3`). Неявное умножение `2(3+4)` не поддерживается — между множителями необходим знак `*`.

Вычисления производятся с помощью `Decimal` с контекстом **25 значащих цифр** и режимом округления **`ROUND_HALF_UP`**. Округление при необходимости выполняется **в ходе арифметических операций**, а не исключительно в конце вычисления. Десятичный литерал при преобразовании в `Decimal` первоначально сохраняет свои цифры; арифметика подчиняется указанному контексту. Целочисленный результат функция возвращает как `int`, нецелочисленный — как `Decimal`.

Сначала вычисляются вложенные скобки, затем умножение и деление, затем сложение и вычитание. Операции одинакового приоритета выполняются слева направо.

Примеры:

```bash
uv run python -m toolkit calc "2+3"                   # 5
uv run python -m toolkit calc "2+3*4"                 # 14
uv run python -m toolkit calc "(2+3)*4"               # 20
uv run python -m toolkit calc "-5+10"                 # 5
uv run python -m toolkit calc "(2.5e2-50)/4"          # 50
uv run python -m toolkit calc "1/3"                   # 0.3333333333333333333333333
```

## 7. Проверка выражений калькулятора

До вычисления программа проверяет допустимые символы, правильность числовых литералов и научной записи, отсутствие пробелов внутри числа, последовательность скобок, расположение операторов и наличие операндов. Деление на ноль также обрабатывается как ошибка.

Примеры:

```bash
uv run python -m toolkit calc "2+a"   # ошибка: недопустимый символ: a
uv run python -m toolkit calc "2/0"   # ошибка: деление на ноль
```

Сообщения об ошибках направляются в `stderr`, код завершения — `2`. В вычислительном ядре ошибки выражаются исключением `ValueError`; сам калькулятор не читает ввод и не печатает результаты.

## 8. Конвертер величин

Основная функция: `convert(value, from_unit, to_unit)` в `converter.py`.

Конвертер проверяет число, существование единиц и принадлежность обеих единиц одной категории. Регистр букв в обозначениях единиц не имеет значения. Результат возвращается типом **`float`**.

## 9. Поддерживаемые единицы

| Категория | Единицы |
| --- | --- |
| Длина | `mm`, `cm`, `m`, `km` |
| Масса | `g`, `kg` |
| Температура | `c` (Цельсий), `f` (Фаренгейт), `k` (Кельвин) |

Примеры:

```bash
uv run python -m toolkit convert 100 --from cm --to m    # 1.0
uv run python -m toolkit convert 1000 --from g --to kg   # 1.0
uv run python -m toolkit convert 0 --from c --to f       # 32.0
uv run python -m toolkit convert 100 --from CM --to M    # 1.0
```

Длина и масса пересчитываются через базовые единицы — метр и килограмм. Для температур используются формулы преобразования с промежуточным представлением в градусах Цельсия.

## 10. Проверка данных конвертера

Конвертер отклоняет неизвестные единицы, несовместимые категории (например, `kg` → `m`), некорректные строки вместо чисел и температуры ниже абсолютного нуля: `0 K`, `−273.15 °C`, `−459.67 °F` — допустимые граничные значения.

Примеры ошибочных вызовов:

```bash
uv run python -m toolkit convert abc --from cm --to m
uv run python -m toolkit convert 10 --from kg --to m
uv run python -m toolkit convert -1 --from k --to c
```

При ошибке CLI выводит сообщение в `stderr` и завершает процесс с кодом `2`.

## 11. Описание модулей

- `calculator.py` — проверка и рекурсивное вычисление арифметических выражений со скобками.
- `converter.py` — проверка параметров и перевод величин.
- `constants.py` — коэффициенты и обозначения единиц, максимальная вложенность скобок калькулятора.
- `errors.py` — функции, создающие исключения `ValueError`.
- `__main__.py` — разбор аргументов командной строки, печать результатов и ошибок, коды завершения.

## 12. Автоматическое тестирование

```bash
uv run python -m pytest
```

Тесты разделены на файлы `test_calculator.py` (арифметика, точность, научная запись, скобки, валидация), `test_converter.py` (единицы, температуры и ошибки), `test_cli.py` (запуск команд, вывод и коды завершения). Положительные и отрицательные сценарии проверяются отдельно.

## 13. Принципы реализации

Проект разделяет консольный интерфейс и вычислительное ядро, использует отдельные функции валидации, исключения для ошибок и тесты без запуска отдельного процесса для вычислительных модулей. Для тестов CLI используется `subprocess`.

## 14. Проверка качества кода

```bash
uv run ruff check .
```

Если нужны автоматические исправления замечаний Ruff, можно отдельно выполнить `uv run ruff check . --fix`, предварительно просмотрев предлагаемые изменения.

## 15. Заключение

- Калькулятор поддерживает вложенность скобок не более **900 уровней** (`MAX_BRACKET_DEPTH`).
- Конвертер использует `float`: для некоторых дробных преобразований возможны обычные погрешности двоичного представления, например `173.14999999999998` вместо `173.15`.

Проект предназначен для выполнения обязательных задач лабораторной работы № 1: вычисления арифметических выражений, преобразования величин, проверки ошибок и работы через CLI.
